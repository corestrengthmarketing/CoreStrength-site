# CoreStrength-site
# CoreStrength Marketing Co.

A modern, high-converting website for **CoreStrength Marketing Co.** — a premium digital marketing agency focused on helping businesses generate leads, increase conversions, and scale revenue through performance-driven marketing systems.

---

## 🚀 Overview

This project is a fully responsive agency website designed to:

* Attract high-quality leads
* Communicate a premium brand image
* Drive users toward booking a strategy call

Built with a clean, minimal UI and a strong focus on conversion.

---

## ⚡ Features

* Modern, premium design (dark UI with blue accents)
* Mobile-responsive layout
* Conversion-focused sections (hero, services, process, CTA)
* Lead capture form (Formspree integration)
* Calendly booking integration
* Smooth layout and structured user flow

---

## 🧱 Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Formspree (form handling)
* Calendly (booking system)
